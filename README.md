# CS2-Buhayan-DzeyFrancis

Description
This program calculates the total travel fare based on the distance traveled and the number of passengers, using a fixed fare rate of PHP 14 per kilometer.

 Version 1
- Original code without input validation.
- Input: Accepts a passenger's name, travel distance in kilometers, and number of passengers.
- Process: Multiplies the distance by the fixed fare rate of PHP 14 and the number of passengers.
- Output: Displays the passenger's name and total fare in PHP, rounded to two decimal places.
- Does not include input validation.
